# Autonomous Multi-Agent Support Triage System

An enterprise-grade, state-orchestrated multi-agent support automation pipeline built with **LangGraph**, **Supabase (PostgreSQL)**, and **TypeScript**.

---

## 🏗️ System Architecture

\`\`\`mermaid
flowchart TD
    Start([Incoming Customer Query]) --> Triage[Triage Agent]
    Triage -->|Classify & Score| Data[Data Agent - RAG]
    Data -->|Fetch SOPs / Context| Action[Action Agent]
    Action -->|Persist Ticket & Resolution| Supabase[(Supabase Database)]
    Action --> End([Resolved Response / Audit Trail])
\`\`\`

### Agents Breakdown
- **Triage Agent (`src/agents/triageAgent.ts`)**: Classifies queries into categories (`technical_bug`, `billing`, `urgent_escalation`, `general_query`).
- **Data Agent (`src/agents/dataAgent.ts`)**: Fetches matching Standard Operating Procedures (SOPs) from Supabase.
- **Action Agent (`src/agents/actionAgent.ts`)**: Synthesizes the final resolution and logs tickets into the Supabase database.

---

## 🛠️ Tech Stack
- **Language/Runtime:** TypeScript / Node.js
- **Orchestration:** `@langchain/langgraph`
- **Database:** Supabase (PostgreSQL with RLS)

---

## 🚀 How to Run & Use

### 1. Configure Environment Variables
Create a `.env` file in the root directory:
\`\`\`env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
\`\`\`

### 2. Database Setup (Supabase SQL Editor)
Run the following schema in your Supabase SQL Editor:
\`\`\`sql
CREATE TABLE public.company_knowledge (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT NOT NULL,
    category TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE public.support_tickets (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    customer_email TEXT NOT NULL,
    query TEXT NOT NULL,
    category TEXT NOT NULL,
    resolution TEXT NOT NULL,
    status TEXT DEFAULT 'open',
    created_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE public.company_knowledge ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.support_tickets ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Full access knowledge" ON public.company_knowledge FOR ALL TO service_role USING (true) WITH CHECK (true);
CREATE POLICY "Full access tickets" ON public.support_tickets FOR ALL TO service_role USING (true) WITH CHECK (true);
\`\`\`

### 3. Seed Knowledge Base
\`\`\`bash
npx tsx src/seed.ts
\`\`\`

### 4. Run Multi-Agent System
\`\`\`bash
npx tsx src/index.ts
\`\`\`

### 5. Inspect Logged Tickets
\`\`\`bash
npx tsx src/view-tickets.ts
\`\`\`
